# QA network (work in progress)

This staging composition defines a VPC with six subnet categories across two zones (the third CIDR block of each category stays reserved), one NAT gateway, routing, and S3/DynamoDB gateway endpoints. The eleven interface endpoint services are optional and disabled by default; set `enable_interface_endpoints = true` only when needed and after reviewing their cost. It is deliberately limited to staging: production requires a NAT per zone. The `endpoint_client_security_group_id` output permits HTTPS to the gateway endpoint prefix lists; when interface endpoints are enabled, it also permits HTTPS to those endpoints. The owning compositions must attach the group to authorized workloads; it does not replace their other security groups. Without interface endpoints, this module does not provide private ECR or SSM connectivity.

**Not ready to apply:** AWS integration tests and the intended restrictions on workload and endpoint access are not complete. This composition outputs subnet IDs and route table IDs; EKS, the bastion, and their service-specific security groups belong to later tasks. Per ADR-0036, the lab retains the default NACL, which permits traffic and is not an additional restrictive barrier. No restrictive gateway endpoint policy or application IAM policy is configured here: the endpoint client security group only restricts network destinations, not S3 buckets, DynamoDB tables, or API actions. Those permissions must be specified and verified when the consumers and resources are defined. NAT and optional interface endpoints generate ongoing charges; review the budget before any deployment.

For Learner Lab, copy `backend.hcl.example` to the ignored `backend.hcl` and set the existing bucket and KMS alias. Use `40-red/terraform.tfstate`, separate from bootstrap. This S3 key retains its previous name to avoid changing the state location when the local directory is renamed. Copy `lab.tfvars.example` to ignored `lab.tfvars`, verify that all listed availability zones are available in the account, and fill the required tags. Run `terraform init '-backend-config=backend.hcl'`, `terraform validate`, and `terraform plan '-var-file=lab.tfvars'` only after the module is complete. The primary region is `us-east-1` and the recovery region is `us-west-2`. This composition does not create the recovery network yet.

Reference: DOC-INF-02 sections 2–5 and DOC-A-INF-06 sections 3 and 10.1. The endpoint group is separate from the security groups for EKS nodes and management; attaching it is required before those workloads can reach the interface endpoints.
